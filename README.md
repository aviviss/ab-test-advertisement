# a/b-тест рекламной кампании
проект по продуктовой аналитике на открытом датасете [marketing a/b testing](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing/data)

## задача
сравнить конверсию в покупку у пользователей, видевших рекламу (`ad`), и пользователей, видевших контрольное сообщение (`psa`), оценить величину разницы и её статистическую неопределённость

## данные
- 588 101 пользователь, одна запись на пользователя
- основная метрика - доля пользователей, совершивших покупку (`converted`)
- дополнительные поля - число показов, день и час максимального числа показов
- исходный csv не хранится в репозитории: ноутбук загружает датасет с kaggle через `kagglehub`

## основные результаты
| показатель | ad | psa |
|---|---:|---:|
| пользователей | 564 577 | 23 524 |
| покупок | 14 423 | 420 |
| конверсия | 2,555% | 1,785% |

- абсолютная разница конверсий - **+0,769 п.п.**, 95% ди ньюкомба **[+0,587; +0,936] п.п.**
- относительная разница - **+43,09%**, 95% ди отношения долей **[+29,97%; +57,52%]**
- двусторонний z-тест двух пропорций - **p = 1,705 × 10⁻¹³**

наблюдаемая конверсия в `ad` статистически значимо выше конверсии в `psa` при α = 0,05, однако для причинной интерпретации нужны предпосылки корректно проведённого эксперимента

## что сделано
- проверены пропуски, дубликаты, уникальность пользователей и допустимые значения признаков
- исследовано распределение количества показов, экстремальные значения сохранены без произвольного удаления
- выполнено описательное сравнение экспериментальных групп
- рассчитаны конверсии, доверительные интервалы, абсолютный и относительный uplift
- проведён двусторонний z-тест двух пропорций
- оценена ретроспективная чувствительность теста при α = 0,05 и мощности 80%
- разобраны ограничения данных и условия принятия продуктового решения

## ограничения
- плановая пропорция распределения неизвестна, поэтому нельзя проверить srm
- нет исходных характеристик пользователей и журналов назначения в группы, качество рандомизации по этому файлу не подтверждается
- время покупки и отдельных показов отсутствует, а `most ads day` — день максимального числа показов, а не день покупки
- сравнения конверсий по дням являются описательными, определять по ним оптимальное время рекламы нельзя
- без расходов на рекламу и маржинальной ценности покупки нельзя оценить экономическую эффективность масштабирования
- уровень значимости в учебном анализе не был предзарегистрирован до получения данных
